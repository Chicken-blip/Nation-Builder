# Nation Builder
A turn-based game where you manage your country. Built with Java and JavaFX.

# Status
- Simple UI of Main Scene
- Rendering of changes in Nation stats
- Functioning NEXT TURN button

# Roadmap
- JSON-driven Event System
- Multiple Nations + relations
- Political narrative
- And more...

# How To Run
- Requires Java JDK 17+ and Maven.
```console
mvn javafx:run
```
