# Nation Builder
A turn-based game where you manage your country. Built with Java and JavaFX.

[![wakatime](https://wakatime.com/badge/github/Chicken-blip/Nation-Builder.svg)](https://wakatime.com/badge/github/Chicken-blip/Nation-Builder)

# Status
- Simple UI of Main Scene
- Rendering of changes in Nation stats
- Functioning NEXT TURN button
- JSON-Driven Event system
- JSON-based schema for Buildings and Nations
- Different menus for managing diplomacy, buildings, and other things
- infrastructure to support population happiness
- Appointees to boost output and production
- Law Enactments to provide major bonuses
- Research for long-term, larger benefits
- Population Management menu includes taxes, immigration, rationing, and birth rate policy

# How To Run
- Requires Java JDK 17+ and Maven.
```console
mvn javafx:run
```
# Notes
SimRunner.java is a harness I made to test inflation concerning resources and population - it shouldn't be run when playing the game normally.
