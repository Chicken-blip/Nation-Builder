# Nation Builder
A turn-based game where you manage your country. Built with Java and JavaFX.

# Status
- Simple UI of Main Scene
- Rendering of changes in Nation stats
- Functioning NEXT TURN button
- JSON-Driven Event system
- JSON-based schema for Buildings and Nations
- Different menus for managing population, diplomacy, buildings, and other things
- infrastructure to support population happiness

# Roadmap
- Military management
- Research
- Political narrative
- Policies
- Save/Load support
- Expansion on events, nations, buildings, resources, and infrastructure
- Plenty of bugs and bug fixes
- And more...

# How To Run
- Requires Java JDK 17+ and Maven.
```console
mvn javafx:run
```
# Notes
SimRunner.java is a harness I made to test inflation concerning resources and population - it shouldn't be run when playing the game normally.
